# Два таймера и USART на ATmega8

Учебный проект на AVR Assembler: два независимых аппаратных таймера формируют события, по которым микроконтроллер отправляет `ping\r\n` и `pong\r\n` через USART. Представлены три варианта программы по уровням сложности.

Параметры проекта: **ATmega8, 16 МГц, USART 9600 бод, 8N1**. Сборка выполняется через **AVRA**; для симуляции приложена схема **SimulIDE**.

## Задание

1. **Стандартная сложность.** Запустить два параллельных таймера с интервалами `TIMER1_INTERVAL` и `TIMER2_INTERVAL`. По срабатыванию первого выводить `TIMER1_STR = "ping\r\n"`, второго — `TIMER2_STR = "pong\r\n"`.
2. **Средняя сложность.** Выполнить стандартный вариант, обеспечить точность времени вывода до 4 тактов и найти минимальную сумму интервалов, при которой программа работает корректно.
3. **Высокая сложность.** Дополнить средний вариант командами USART для изменения обоих интервалов и строк, а также перезапуска таймеров. При изменении параметров проверять возможность корректной работы и сообщать об ошибке. На время вычислений таймеры останавливать нельзя.

## Команды высокой сложности

Команды вводятся заглавными буквами, без пробелов вокруг `=`. Завершайте команду символом `CR`, `LF` или парой `CRLF` — обычно это настройка отправки по Enter в терминале. Пустые команды игнорируются.

| Команда | Действие |
| --- | --- |
| `T1=100` | Установить интервал первого таймера в 100 мс |
| `T2=160` | Установить интервал второго таймера в 160 мс |
| `S1=hello` | Заменить текст первого сообщения на `hello` |
| `S2=world` | Заменить текст второго сообщения на `world` |
| `S1=` / `S2=` | Установить пустой текст; передаваться будет только `\r\n` |
| `RESET` | Перезапустить отсчёт обоих таймеров и очистить ожидающие сообщения |
